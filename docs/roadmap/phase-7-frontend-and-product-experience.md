# PHASE 6 — Frontend and Product Experience

Build a professional financial investigation dashboard.

Technology:

- Next.js.
- React.
- TypeScript.

Main sections:

1. Overview dashboard.
2. Reconciliation cases.
3. Case investigation details.
4. Agent execution trace.
5. Evidence viewer.
6. Human approval interface.
7. Evaluation dashboard.

The case investigation screen must show:

- Original financial records.
- Identified discrepancies.
- Financial impact.
- Evidence references.
- Agent investigation steps.
- Tool execution results.
- Current case status.
- Human approval controls.

Provide a live visualization of LangGraph execution.

The UI must distinguish clearly between:

- Confirmed facts.
- Agent hypotheses.
- Missing evidence.
- Human decisions.

Use a professional enterprise SaaS design.

Connect the frontend to the actual FastAPI backend.

Do not use hardcoded mock responses in the final implementation.
